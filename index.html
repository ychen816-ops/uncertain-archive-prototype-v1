About the project

How does partial visual information change the way an image is categorized?

Project description

This project explores how partial visual information changes the way an image is categorized. It uses a Teachable Machine model trained on humorous and visually ambiguous images. As an image is gradually erased into view, the four category labels move and change with the model’s confidence.

Faces in Things

Everyday objects or still-life elements accidentally form the appearance of a face.

Shape Imitation

One thing copies or resembles the recognizable form of another.

Material Illusion

Something appears to be made from a material that it is not.

Forced Perspective

Camera angle, distance, or scale changes how objects appear to relate in space.
